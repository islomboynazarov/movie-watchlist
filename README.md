# 🎬 Movie Watchlist App

A project built three times to master the evolution from vanilla scripting to a modern, type-safe React architecture.

## 🚀 The Evolution Path
This repository uses **Git Branches** to show the project at different stages of development. You can switch between them to see how the code changed.

### 1. Vanilla JavaScript (`branch: vanilla-js`)
*   **Core Focus:** DOM Manipulation, Event Listeners, and LocalStorage.
*   **Tech:** HTML5, CSS3, ES6 JavaScript.
*   **Key Learning:** Managing state manually without a framework.

### 2. React Migration (`branch: react-js`)
*   **Core Focus:** Components, Props, and Hooks (`useState`, `useEffect`).
*   **Tech:** React (Vite), Functional Components.
*   **Key Learning:** Declarative UI and component lifecycle.

### 3. TypeScript Refactor (`branch: main` or `react-ts`)
*   **Core Focus:** Type Safety and Interfaces.
*   **Tech:** React, TypeScript.
*   **Key Learning:** Defining `Movie` interfaces, typing Event Handlers, and catching bugs at compile-time.
